# Golf for Good - Charity Golf Platform

A subscription-driven web application combining golf performance tracking, charity fundraising, and monthly draw-based rewards.

## Features

- User subscription (Monthly/Yearly)
- Stableford score entry (last 5 scores)
- Monthly draw system (Random or Algorithmic)
- Charity support (minimum 10% of subscription)
- Admin dashboard for managing draws, users, and charities

## Tech Stack

- Backend: Flask (Python)
- Database: Supabase
- Frontend: HTML/CSS/JavaScript

## Deployment

This app is deployed on Render.com

## Environment Variables Required

- `SUPABASE_URL`
- `SUPABASE_SERVICE_KEY`
- `SECRET_KEY`
