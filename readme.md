# Toyota Real-Time Chat Application 🚗💬

A beautiful, real-time chat application with Toyota-themed design, built with WebSocket technology.

## ✨ Features

- 🔐 **User Authentication** - Secure login and registration
- 💬 **Real-time Messaging** - Instant message delivery using WebSockets
- 🏠 **Chat Rooms** - Multiple chat rooms (General, Tech, Random, etc.)
- 👤 **Private Messages** - One-on-one private conversations
- 📎 **File Sharing** - Share images and documents
- 🟢 **User Presence** - See who's online/offline
- 🔔 **Notifications** - Get notified of new messages
- 📜 **Chat History** - Persistent message storage
- 🎨 **Beautiful UI** - Toyota color scheme (Green, Purple, Navy Blue)
- 🌙 **Dark Mode** - Easy on the eyes

## 🛠️ Technology Stack

### Frontend
- HTML5
- CSS3 (with custom properties)
- JavaScript (ES6+)
- WebSocket API
- Font Awesome Icons

### Backend
- Python 3.8+
- WebSockets library
- SQLite3 database
- Asyncio
